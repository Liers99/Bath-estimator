# Bath Estimator — Stone Ridge Remodeling

Onsite bath remodel ballpark estimator.

## Deploy to Vercel

1. Push this repo to GitHub
2. Go to vercel.com → New Project → Import your GitHub repo
3. Vercel auto-detects Create React App — just click Deploy
4. Done. Your app is live.

## Add to iPhone Home Screen

1. Open your Vercel URL in Safari on iPhone
2. Tap the Share button (box with arrow)
3. Tap "Add to Home Screen"
4. Tap Add — done

## Update Pricing

Open `src/App.jsx` and find `DEFAULT_FEATURES` at the top.
Each item has a `range: [low, high]` — edit those numbers and push to GitHub.
Vercel redeploys automatically.
